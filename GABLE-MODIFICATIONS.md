## Preserve JavaScript destructuring defaults in the generic AST

- **Kind:** upstream-bound
- **Upstream pull request:** not yet opened
- **Carried since:** 2026-11-19
- **What it does:** keeps the default expressions of destructured parameters
  and bindings (`function f({ limit = 10 })`, `const { a = f() } = obj`) in the
  generic AST and exports them through the existing v1 schema. Naming keeps
  source keys and local aliases apart, and IL lowering evaluates a default only
  for an undefined input.
- **Retires when:** an upstream release includes it.
