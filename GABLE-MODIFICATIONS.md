## Keep dotted and numeric keys of Python mapping patterns

- **Kind:** upstream-bound
- **Upstream pull request:** not yet opened
- **Carried since:** 2026-11-20
- **What it does:** a Python mapping pattern with a dotted or numeric key
  (`case {Color.RED: x, 1: y}`) becomes a list of key/value pairs instead of a
  record pattern that drops those entries. Mappings whose keys are all plain
  names or strings are unchanged.
- **Retires when:** an upstream release includes it.
